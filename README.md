## 📖 Sobre o projeto

O **CloudForge** nasceu da minha curiosidade em conhecer e experimentar o **Google Antigravity**, explorando suas possibilidades como ferramenta de desenvolvimento assistido por inteligência artificial.

Como estou me preparando para a certificação **AWS Certified Solutions Architect – Associate (SAA-C03)**, decidi aproveitar essa experiência para criar algo que também contribuísse para os meus estudos.

A ideia é construir, gradualmente, um ambiente de aprendizado inspirado em jogos, combinando conceitos de computação em nuvem, arquitetura AWS e elementos de gamificação.

O projeto também funciona como um espaço para experimentar novas abordagens de desenvolvimento com IA, avaliar ferramentas e aprender durante o processo.

## 🎯 Objetivos

- Explorar o Google Antigravity e seus recursos de desenvolvimento assistido por IA.
- Experimentar novas formas de trabalhar com agentes de inteligência artificial.
- Reforçar os conhecimentos adquiridos durante a preparação para a certificação AWS.
- Praticar conceitos de serviços e arquiteturas de nuvem.
- Explorar possibilidades de gamificação aplicadas ao aprendizado técnico.

## 🏛️ Conceito

O CloudForge utiliza referências de mitologia grega e jogos retrô para criar uma identidade visual própria.

A proposta é transformar o estudo de serviços AWS em uma experiência mais visual e interativa.

O nome **CloudForge** representa essa ideia: uma forja onde conhecimentos sobre computação em nuvem são construídos e aprimorados.

## 🛠️ Tecnologias e ferramentas

O projeto explora tecnologias de desenvolvimento web, incluindo:

- React
- TypeScript
- Google Antigravity
- Git e GitHub

**AWS:** utilizada como referência técnica e conteúdo de estudo, sem necessidade de provisionar recursos reais na nuvem.

## 🚧 Status do projeto

**Em desenvolvimento — projeto experimental.**

O CloudForge ainda não está finalizado.

Atualmente, estou explorando a ferramenta, desenvolvendo funcionalidades gradualmente e experimentando diferentes possibilidades para a plataforma.

Entre os recursos já explorados estão:

- Catálogo de serviços AWS.
- Visualização de informações sobre serviços.
- Relacionamentos entre serviços AWS.
- Interface inspirada em jogos e mitologia.

Novas funcionalidades poderão ser adicionadas, modificadas ou descartadas conforme o desenvolvimento evoluir.

> Este repositório é um ambiente de experimentação e aprendizado, não uma aplicação pronta para produção.

## 📚 Aprendizado

O CloudForge reúne dois objetivos pessoais:

**1. Desenvolvimento com inteligência artificial**

Compreender melhor como ferramentas de IA podem participar do desenvolvimento de software, explorando suas possibilidades, limitações e diferentes formas de utilização.

**2. Preparação para a certificação AWS**

Consolidar conceitos relacionados aos serviços AWS, suas características e seus relacionamentos, desenvolvendo uma compreensão mais prática das decisões de arquitetura.

O projeto não substitui os materiais oficiais de estudo nem os laboratórios práticos da AWS.

## 📌 Observações

Este é um projeto pessoal, desenvolvido para fins educacionais e experimentais.

Não possui vínculo oficial com a Amazon Web Services ou o Google.
